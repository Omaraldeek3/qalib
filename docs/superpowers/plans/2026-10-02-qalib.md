# Qalib Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A bilingual library of 108 website designs, each with a live demo and a Claude Code prompt, deployed to qalib.omardeek.tech.

**Architecture:** Designs are data. A build script renders every design to static HTML with React (`renderToStaticMarkup`), shared section markup, a base stylesheet and one kit stylesheet per style. The Next.js 16 app lists the designs, frames the demos and builds prompts from the same data.

**Tech Stack:** Next.js 16 (App Router, Turbopack), React 19, TypeScript 6, plain CSS, fontsource, lucide-static, sharp, tsx, node:test, Playwright (msedge).

**Spec:** `docs/design.md`

**Execution note:** written for an overnight run in one session (Omar asked to go ahead while asleep; no subagents). Tasks name files, interfaces and checks; the code is written directly into the files rather than duplicated here.

## Global Constraints

- 18 styles × 6 designs = 108 designs; slugs unique, kebab-case.
- Every text in demos and UI exists in Arabic and English; Arabic pages are `lang="ar" dir="rtl"`.
- No letter-spacing and no text-transform on Arabic text.
- No third-party requests from the library or the demos (fonts and images self-hosted).
- Demo HTML uses relative URLs only (`../../fonts/…`, `../../img/…`).
- Commits use `Omar Aldeek <91458782+Omaraldeek3@users.noreply.github.com>`.
- Repository private; site public on qalib.omardeek.tech.
